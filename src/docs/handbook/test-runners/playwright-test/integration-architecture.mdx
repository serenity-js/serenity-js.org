# Integration architecture

Serenity/JS works alongside Playwright Test, with each tool responsible for a different part of a test run. Playwright Test discovers, schedules, and runs scenarios; the [`@serenity-js/playwright-test`](/api/playwright-test) [test runner adapter](/handbook/architecture/#serenityjs-test-runner-adapters) makes Serenity/JS fixtures available to those scenarios and sends lifecycle information to reporting services as [Domain Events](/handbook/reporting/domain-events). The same integration supports existing Playwright Test scenarios and scenarios written with Screenplay Pattern APIs.
