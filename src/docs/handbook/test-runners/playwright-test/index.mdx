# Playwright Test

Playwright Test gives you a strong foundation for browser and component testing. As a suite grows, though, scenarios can become harder to read, repeated interactions harder to maintain, and a pass or fail result harder to explain. Serenity/JS works alongside Playwright Test to address those problems: it records richer evidence of each scenario and lets you introduce the [Screenplay Pattern](/handbook/design/screenplay-pattern/) where shared user behaviour deserves a common vocabulary.

You do not need to rewrite your suite. Keep using Playwright Test to run scenarios across browsers and platforms, then add Serenity/JS a piece at a time—start with reporting, and introduce Actors, Tasks, and Questions as repeated workflows emerge. The guides below show you how to configure the integration, write scenarios, and add specialised capabilities such as component, multi-actor, and Electron testing.

## Learning path

We recommend following these pages in order to get the most out of the integration:

1. [**Installation**](/handbook/test-runners/playwright-test/installation/) – Set up Playwright Test and add Serenity/JS integration modules.
2. [**Configuration**](/handbook/test-runners/playwright-test/configuration/) – Configure test reports and automatic screenshots.
3. [**Writing tests**](/handbook/test-runners/playwright-test/writing-tests/) – Write test scenarios using Serenity/JS Screenplay Pattern APIs.
4. [**Component testing**](/handbook/test-runners/playwright-test/component-testing/) – Test components in isolation using the same Interaction Objects as integration tests.
5. [**Multi-actor scenarios**](/handbook/test-runners/playwright-test/multi-actor-scenarios/) – Implement scenarios with multiple actors and independent browsers.
6. [**Customising actors**](/handbook/test-runners/playwright-test/customising-actors/) – Modify abilities, share notes, and replace the default cast.
7. [**Testing Electron apps**](/handbook/test-runners/playwright-test/electron-testing/) – Test desktop Electron applications with Serenity/JS.
8. [**Reporting**](/handbook/test-runners/playwright-test/reporting/) – Choose the Serenity/JS HTML Reporter, Serenity BDD Reporter, and native Playwright tools.
9. [**Integration architecture**](/handbook/test-runners/playwright-test/integration-architecture/) – Understand how Serenity/JS integrates with Playwright Test.
